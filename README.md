# Minha Lista de Filmes

**Atividade 4 — somente a versão 1.**

Cadastro de filmes e marcação de assistidos com persistência SQLite, incluindo suporte Web.

## Estrutura

- `versao1/`: projeto Flutter completo da versão publicada.

## Executar o Flutter

Instale o Flutter compatível com `versao1/pubspec.yaml` e execute:

```powershell
cd versao1
flutter pub get
flutter run -d chrome
```

## Verificação básica

```powershell
flutter analyze
flutter build web
```
